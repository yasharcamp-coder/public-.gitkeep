# سیستەمی حازربوونی کارمەندان
MVP responsive web app for employee attendance.

## Run
1. Install Node.js 20+.
2. `npm install`
3. `npm start`
4. Open `http://localhost:3000`

Database is SQLite (`attendance.db`). For production online deployment, move the database to PostgreSQL or another persistent managed database and add authentication, backups, GPS/geofencing, roles and audit logs.
